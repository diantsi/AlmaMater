# US-15a — Event topic

- **Status:** In scope (MVP)
- **Journey step:** 3. Fill in event details
- **Source story:** US-15
- **Dependencies:** US-07

## User story

> As an organiser, I want to choose an event topic from a predefined list, so that students can find it using a topic filter.

## Description

Choose a topic from a predefined list.

## Acceptance criteria

- **Given** the form offers predefined topics, **when** an organiser selects one and publishes the event, **then** the selected topic is stored, displayed, and usable by the topic filter.
- **Given** a submitted topic is not among the predefined options, **when** publication is attempted, **then** the value is rejected.
