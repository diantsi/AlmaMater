# US-49 — Browse events

- **Status:** In scope (MVP)
- **Journey step:** 6. Success
- **Source story:** US-49
- **Dependencies:** US-39

## User story

> As a student, I want to browse events on the `Events` page, so that I can discover activities outside the organiser’s social channels.

## Description

Browse events on the `Events` page.

## Acceptance criteria

- **Given** active published events exist, **when** a student opens the `Events` page, **then** the student can browse listings and select one to view details.
- **Given** no active events match the current view, **when** the page opens, **then** it displays a clear empty state.
