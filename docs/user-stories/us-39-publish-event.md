# US-39 — Publish event

- **Status:** In scope (MVP)
- **Journey step:** 5. Preview, validate, and publish
- **Source story:** US-39
- **Dependencies:** US-03, US-36

## User story

> As an organiser, I want to publish a completed event using a clear action, so that it becomes visible in the catalog.

## Description

Publish a completed event using a clear action.

## Acceptance criteria

- **Given** an authorised organiser has an event that passes validation, **when** the organiser selects “Publish,” **then** the event becomes visible in the `Events` catalog under the correct organisation.
- **Given** validation or authorisation fails, **when** publication is attempted, **then** the event remains unpublished.
