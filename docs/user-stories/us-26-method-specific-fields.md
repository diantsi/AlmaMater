# US-26 — Method-specific fields

- **Status:** In scope (MVP)
- **Journey step:** 4. Choose participation method and channels
- **Source story:** US-26
- **Dependencies:** US-25

## User story

> As an organiser, I want to see only the participation fields relevant to my chosen method, so that I can complete the form without irrelevant inputs.

## Description

Show only participation fields relevant to the selected method.

## Acceptance criteria

- **Given** an organiser selects a participation method, **when** the participation section updates, **then** inputs relevant to that method are shown and irrelevant inputs are not required.
- **Given** the organiser changes the method, **when** the section updates, **then** inputs and validation correspond to the new method.
