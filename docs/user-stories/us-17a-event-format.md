# US-17a — Event format

- **Status:** In scope (MVP)
- **Journey step:** 3. Fill in event details
- **Source story:** US-17
- **Dependencies:** US-07

## User story

> As an organiser, I want to specify whether the event is online or in person, so that students understand its format.

## Description

Specify whether the event is online or in person.

## Acceptance criteria

- **Given** the form offers online and in-person formats, **when** the organiser selects one and publishes, **then** the selected format appears accurately on the listing.
- **Given** the organiser changes the format before publication, **when** the event is published, **then** only the final selection is presented.
