# US-43 — Shareable event link

- **Status:** In scope (MVP)
- **Journey step:** 6. Success
- **Source story:** US-43
- **Dependencies:** US-39, US-55b

## User story

> As an organiser, I want a shareable event link, so that I can distribute the listing through existing channels.

## Description

Provide a shareable event link.

## Acceptance criteria

- **Given** an event has been published, **when** its confirmation or details page opens, **then** a stable URL is available and resolves to that event for a signed-in university member.
- **Given** an event has not been published, **when** the organiser looks for its public URL, **then** the platform does not present it as a public listing.
