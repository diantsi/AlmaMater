# US-25 — Participation method

- **Status:** In scope (MVP)
- **Journey step:** 4. Choose participation method and channels
- **Source story:** US-25
- **Dependencies:** US-07

## User story

> As an organiser, I want to select one participation method—Google Form, direct contact, or open attendance—so that students know how to join.

## Description

Select one participation method.

## Acceptance criteria

- **Given** an organiser selects Google Form, direct contact, or open attendance, **when** the selection is saved, **then** exactly one participation method is associated with the event.
- **Given** the organiser switches methods, **when** the form updates, **then** only the latest method remains active.
