# US-07 — Start event creation

- **Status:** In scope (MVP)
- **Journey step:** 2. Start “Create event”
- **Source story:** US-07
- **Dependencies:** US-02, US-03

## User story

> As an organiser, I want to start creating an event from a clearly labelled action, so that I can publish an opportunity without searching for the form.

## Description

Start event creation from a clearly labelled action.

## Acceptance criteria

- **Given** an authorised organiser is on the organisation dashboard, **when** the organiser selects “Create event,” **then** an event-creation form opens ready for input.
- **Given** a user lacks organisational publishing permission, **when** the user attempts to open the creation workflow, **then** access is denied.
