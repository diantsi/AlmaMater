You are an experienced Product Manager and Business Analyst.

We are developing **AlmaMater**, a university platform that helps students discover events, projects, and teams, while enabling organisers to publish opportunities for students.

Based on the provided list of User Stories, define the boundaries of the MVP (**Scope Boxing**).

### Tasks

1. Divide all User Stories into two groups:
   - **In Scope (MVP)** — features that must be implemented by the end of the course.
   - **Out of Scope (Post-MVP)** — features that can be postponed.
2. Keep only the minimum set of features required to support the core user scenario.
3. Consider the student team's limited resources and development timeline.
4. Briefly justify the decision for each User Story.
5. Preserve the grouping of stories according to the User Journey stages.

Present the results in a table with the following columns:

- User Journey Stage
- User Story
- In Scope / Out of Scope
- Justification
