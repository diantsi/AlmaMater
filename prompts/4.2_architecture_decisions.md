### Selected decisions

1. **One repository with frontend/backend folders.** Benefits: shared API versions, documentation, and change review. Trade-off: discipline around module boundaries.
2. **React + Vite using JavaScript.** Benefits: components for forms and the catalog, building on JS. Trade-off: learning React, routing, and API integration.
3. **Python + FastAPI + SQLAlchemy.** Benefits: API development and typed schemas. Trade-off: authentication and migrations must be assembled separately.
4. **Docker Compose.** Benefit: consistent local environment. Trade-off: an additional dependency for every team member.
