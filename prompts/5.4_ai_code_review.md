# Practice 5.4 — Prompt for the AI Code Review

**Purpose:** Preserve the prompt used to open Pull Requests for the unmerged branches, review them with AI and apply the significant fixes.  
**Date:** 2026-11-11  
**Model:** Claude Opus 5.5 (Claude Code)  
**Target artifacts:** GitHub PRs #2 and #3 (reviews, inline comments, fix commits), DOX docs.

## Prompt

> Run an AI code review for all branches that are not merged into main.
>
> - Create a Pull Request for each unmerged branch, in chronological order. Target a stacked branch at its parent so the PR shows only its own changes.
> - Review each PR diff for architecture conformance, security, error handling and code cleanliness. Post the review on GitHub with inline comments.
> - Fix only the significant findings and push the fixes to the PR branch. Do not merge PRs.
> - Missing auth is a team decision; do not change it.
>
> Use Makefile targets for all executable commands. Install missing tools on D:.
>
> Update applicable DOX documentation after the fixes, verify them with `make check`, and report what was fixed and what was left unchanged.
>
