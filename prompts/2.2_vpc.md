Role: You are an expert Product Manager and UX Researcher specializing in Value Proposition Design and digital platforms.

Context: I am building a university platform called AlmaMater designed to be a centralized hub where students can discover activities, publish ideas, find teammates, and join projects or events.

Students currently struggle because information about university opportunities is scattered across social media, group chats, university websites, emails, and other communication channels. Students with project ideas may also struggle to find teammates with relevant skills. Student organizations and university staff need effective ways to reach interested students, recruit participants, and promote activities.

The platform includes features such as:
- Student profiles with faculty, major, year of study, interests, skills, and languages
- A centralized feed for university events and projects
- Search and filtering by category, date, faculty, and organization
- Project and event publishing
- Join requests and RSVPs
- Teammate discovery
- Built-in communication
- Campus/community map
- Notifications and recommendations
- Google Calendar integration
- Corporate university email authentication

The following Key User Profiles have already been identified:
1. Opportunity-Seeking Students
2. Project Initiators & Idea Generators
3. Student Organizations
4. Faculty & University Staff

Instructions: Your task is to build a Value Proposition Canvas for EACH of the identified Key User Profiles.

Use the existing user profiles as the foundation of the analysis. Do not create additional user groups unless there is a strong reason supported by the project context.

Part 1: Analyze User Needs

For each Key User Profile, identify:

- Jobs: What is the user trying to accomplish? Include practical tasks, goals, and activities that are relevant to the university context and the platform.

- Pains: What problems, obstacles, frustrations, risks, or inefficiencies does the user experience while trying to accomplish these tasks?

- Gains: What outcomes, benefits, improvements, or experiences does the user expect or would find valuable?

Keep Jobs, Pains, and Gains focused on the USER rather than describing product functionality.

Part 2: Connect Needs to the Product

For each identified user profile, describe:

- Solution: How can specific AlmaMater features address the identified Jobs, Pains, and Gains?

Solutions should reference concrete product functionality rather than generic statements.

Examples of relevant functionality include:
- Centralized event and project feed
- Student profiles
- Search and filters
- Project and event publishing
- Teammate discovery
- Join requests and RSVPs
- Built-in chat
- Notifications
- Recommendations
- Campus/community map
- Google Calendar integration
- Corporate university email authentication

CRITICAL CONSTRAINTS:

- Keep the analysis consistent with the previously identified Key User Profiles.
- Do not invent unrelated user needs simply to justify existing features.
- Jobs, Pains, and Gains must describe the user's situation independently of AlmaMater.
- Do not describe product features as Jobs or Gains.
- The Solution column must explicitly connect user needs to relevant platform functionality.
- Avoid generic marketing statements such as "improves the user experience" or "provides great value."
- Focus on specific, realistic university scenarios and behaviors.
- Do not assume that every feature is relevant to every user profile.
- Avoid duplicating the same Jobs, Pains, and Gains across all profiles unless they genuinely apply.

Output Format:

Create a professional Markdown document.

Use the following structure:

# Value Proposition Canvas

## Overview

Provide a short explanation of the purpose of the Value Proposition Canvas and how it relates to the previously identified Key User Profiles.

## Value Proposition Canvas

Create a Markdown table with the following columns:

| User Profile | Jobs | Pains | Gains | Solution |
|--------------|------|-------|-------|----------|

Create one row for EACH of the following user profiles:
- Opportunity-Seeking Students
- Project Initiators & Idea Generators
- Student Organizations
- Faculty & University Staff

For readability, use <br> tags or short bullet-style statements inside table cells.

## Key Product Implications

After the table, briefly summarize the most important product implications revealed by the analysis.

Focus on:
- Which platform capabilities are relevant across multiple user groups
- Which capabilities are specific to particular user groups
- Where the needs of different user groups interact

Do not rank user groups or features unless there is sufficient evidence to support such prioritization.

The final output must be valid Markdown and ready to be added directly to the project's README.md.
